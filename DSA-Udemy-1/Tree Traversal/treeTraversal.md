# Tree Traversal(TT)

- TT is a way to traverse through Trees.
- When we traverse through a LinkedList then it's very simple and staringht forward.
- Traversing throgh a binary tree is bit tricky. This is done by two ways:
  - Breadth First Search(BFS): We start from top, then go to the next line and so on
  - Depth First Search(DFS):
    - Pre Order
    - Post Order
    - In Order
